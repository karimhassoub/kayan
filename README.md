# Kayan — Construction Core

Custom Frappe application for construction-sector business logic
and integrations.

## Application

- Technical app name: `kayan`
- Functional name: `Construction Core`
- Target framework: Frappe v16

## Architecture

All construction-specific custom business logic will live inside
this application.

Upstream applications must remain untouched.

The application will integrate with the future ERP stack without
modifying upstream source code.

## Current Status

Initial application skeleton only.

No business DocTypes or business logic have been implemented yet.
